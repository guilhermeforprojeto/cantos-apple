# Prompts prontos

## Corrigir o projeto todo

```text
Leia https://github.com/guilhermeforprojeto/cantos-apple e siga o AGENTS.md. Corrija os cantos de todo o projeto.
```

## Só um componente

```text
/cantos-apple no componente src/components/SearchBar.tsx. O input tem 16px de raio e 6px de padding; o botão dentro dele está com o mesmo raio.
```

## Criar tokens de raio para o design system

```text
/cantos-apple: em vez de corrigir componente por componente, crie tokens de raio (fora e dentro, por nível de aninhamento) no nosso tema e troque os valores soltos por eles. Mostre a tabela antes de aplicar.
```

## Revisar um design no Figma (com o Figma MCP)

```text
/cantos-apple: leia o frame selecionado no Figma, aponte os pares de camadas aninhadas que não estão concêntricos e diga o raio certo de cada uma. Ative corner smoothing 60% onde fizer sentido.
```
